# production-ready depth target

This release deliberately targets a product depth beyond the Airline Operations benchmark by combining an authentic external-source contract with the existing mathematical/AI stack.

## External empirical backbone
- **Source:** UCI Machine Learning Repository — SECOM
- **Scale/domain:** 1,567 production entities × 591 process measurements; pass/fail yield labels
- **Decision grain:** lot / wafer / process signal
- **Historical intelligence:** yield-excursion and process-signal chronology
- **Named empirical case study:** SECOM yield-excursion signal triage

## Required analytical chain
Source provenance → data quality → entity drilldown → historical/cohort analysis → diagnostic ranking → unique predictive ML → repository-authored algorithm → project-native OR/simulation → counterfactual challenge → human action.

Offline acceptance never calls schema-aligned reference fixtures 'real data'. The source refresh script is the promotion path to empirical mode.
