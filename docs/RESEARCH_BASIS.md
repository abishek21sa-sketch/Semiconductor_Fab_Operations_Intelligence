# Research Basis

The repository uses a synthetic re-entrant MiniFab-style benchmark rather than proprietary production data. This supports reproducible evaluation of semiconductor-fab operations concepts while preserving an explicit evidence boundary.

Research basis used for architecture decisions includes the Intel/ASU MiniFab lineage, MIMAC simulation work, and modern open-source semiconductor-fab scheduling research. These sources motivate re-entrant flow, dispatch-policy evaluation, simulation and predictive/optimization integration; they do not validate this repository against a commercial fab.
